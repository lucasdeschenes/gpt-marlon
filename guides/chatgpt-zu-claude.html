Von ChatGPT zu Claude — der Migrations-Guide

Nimm deine komplette ChatGPT-History, deinen Stil und deine Projekte mit zu Claude — in drei Schritten. Statt bei null anzufangen, exportierst du deinen Kontext, importierst ihn in ein Claude-Project und aktivierst Claudes Memory für dauerhaftes Gedächtnis.

⬇ Als PDF herunterladen 🚀 Community beitreten
ℹ️ Claude Memory, Projects und Skills sind echte Funktionen (Stand 2026, teils Pro/Team). Die Anthropic-Kurse unter anthropic.skilljar.com sind offiziell und kostenlos — „Skills" baust du dort bzw. in Claude selbst, ein automatisches Ein-Klick-Installieren aus einem Kurskatalog gibt es nicht.

Schritt 1 — Deinen „Digital Passport" exportieren

Der offizielle OpenAI-Export ist gut fürs Archiv, aber unübersichtlich. Was du zuerst brauchst, ist eine saubere Zusammenfassung deiner Persönlichkeit und Präferenzen — deinen „Digital Passport". Dafür fügst du Prompt 1 in einen neuen ChatGPT-Chat ein. ChatGPT erstellt daraus ein sauberes Markdown-Dokument (Digital_Passport.md), das du herunterladen kannst.

Schritt 2 — Dein offizielles Archiv herunterladen

Das ist das „Deep Knowledge" — die Rohdaten jedes Gesprächs, das du je geführt hast:

  1. In ChatGPT: Settings → Data Controls aufrufen.
  2. Auf Export Data → Confirm Export klicken.
  3. Die E-Mail von OpenAI abwarten und die .zip-Datei herunterladen.
  4. Aus dem ZIP brauchst du nur die conversations.json.

Schritt 3 — Das „Brain Transplant": Import zu Claude

Wechsle zu Claude. Für beste Ergebnisse nutzt du Claude Projects (verfügbar auf Pro- und Team-Plänen), um alles organisiert zu halten:

  1. Erstelle ein neues Project namens „Mein Kontext".
  2. Lade beide Dateien hoch: Digital_Passport.md und conversations.json.
  3. Füge Prompt 2 ein — Claude nutzt den Passport als Stil-Vorgabe und indexiert deine History.

Pro-Tipp — Global statt Project

Wenn du keine Projects nutzen willst: Gehe zu Claude → Settings → Capabilities → Memory und aktiviere beide Toggles — „Search and reference chats" und „Generate memory from chat history". Damit merkt sich Claude relevanten Kontext über alle Chats hinweg, ohne dass du ein Project brauchst.

3 Dinge, die du sofort tun solltest

  1. Memory aktivieren: Settings → Capabilities → Memory, beide Toggles einschalten.
  2. ChatGPT-Daten exportieren: Settings → Data Controls → Export Data, dann die conversations.json in Claude hochladen.
  3. Weiterlernen: Die offiziellen Anthropic-Kurse unter https://anthropic.skilljar.com/ sind kostenlos und zeigen dir, wie du Claude für deinen Use Case einrichtest — inklusive eigener Claude Skills.

Alle Prompts zum Kopieren

Prompt 1 — Digital Passport in ChatGPT erstellen 
Ich migriere meinen Kontext zu Claude. Bitte analysiere dein Memory, deine Custom Instructions und die letzten Gespräche, um einen umfassenden "Digital Passport" zu erstellen. Enthalte:

1. User Persona: Mein beruflicher Hintergrund und aktuelle Ziele.
2. Kommunikationsstil: Mein bevorzugter Ton und Formatierung.
3. Technische Präferenzen: Tools die ich nutze und Coding-Stile.
4. Key Knowledge: Fakten die du über mein Business oder Leben "gespeichert" hast.

Formatiere als sauberes Markdown-Dokument und stelle eine downloadbare .md-Datei bereit.
Prompt 2 — Kontext in Claude importieren 
Ich migriere meinen kompletten AI-Workspace von ChatGPT. Ich habe zwei Dateien hochgeladen:

1. Digital_Passport.md: Meine Core Persona und Style Guide.
2. conversations.json: Meine rohe Gesprächs-History.

Deine Aufgabe:
• Nutze den Passport als "System Instructions" für unsere Kommunikation.
• Indexiere die conversations.json um meine vergangenen Projekte zu verstehen.
• Gib eine kurze Zusammenfassung wer ich als User bin und liste 3 "Key Insights" die du gewonnen hast, um zu bestätigen dass du die Daten erfolgreich verarbeitet hast.
Mehr davon — jede Woche.
