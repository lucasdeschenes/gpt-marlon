Claude Skills: der komplette Guide

Skills bringen Claude bei, WIE er eine Aufgabe ausführen soll – welche Schritte, welches Format, welche Standards – anders als Memory, das sich nur Fakten über dich merkt. Der Guide erklärt einfach, was ein Skill ist, wie du ihn auf allen Plänen installierst (Anthropic-Skills per Toggle, Community-Skills als ZIP) und stellt 10 sofort einsatzbereite Skills vor. Kein Code nötig – nur einmal einrichten, danach wendet Claude den Skill automatisch an.

01

Was ist ein Skill? – ganz einfach erklärt

Skills und die Memory-Funktion lösen ein ähnliches Problem auf unterschiedliche Weise. Memory merkt sich Fakten über dich („Marlon arbeitet im Marketing, mag kurze Texte"). Was Memory nicht kann: Claude beibringen, WIE er eine komplexe Aufgabe genau ausführt. Genau das tun Skills.

Memory (eingebaut)Skills (du installierst sie)
„Marlon bevorzugt kurze Texte"„Erstelle Reports immer in diesem Format"
Fakten & PräferenzenWorkflows & Qualitätsstandards
Keine Schritt-für-Schritt-LogikExakte, wiederholbare Abläufe

Die Analogie: Ein Skill ist wie die Einarbeitung eines neuen Mitarbeiters – die Claude einmal lernt und nie wieder vergisst.

3 Dinge, die du wissen musst: 1) Einmal einrichten – danach erkennt Claude selbst, wann der Skill relevant ist. 2) Je mehr du verfeinerst, desto besser wird er. 3) Kein technisches Wissen nötig – für Community-Skills lädst du nur eine ZIP-Datei hoch.

02

Installation – Schritt für Schritt

Voraussetzung: Alle Pläne (Free, Pro, Max, Team, Enterprise). Einrichten geht über Desktop/Web, nutzen überall.

Wichtig zuerst – Code-Ausführung aktivieren: Skills funktionieren nicht ohne diese Einstellung. Claude.ai → Einstellungen → Capabilities → „Code execution and file creation" einschalten. Das machst du einmal.

  1. Code-Ausführung einschalten (siehe oben) – der einzige Setup-Schritt.
  2. Skill-Bereich öffnen: In Claude.ai auf Customize → Skills.

3a. Anthropic-Skills einschalten (z. B. Document Suite): bereits integriert – einfach den Toggle einschalten. 3b. Community-Skill als ZIP hochladen: Skill-Ordner von GitHub herunterladen → als ZIP komprimieren → + → Upload a skill → ZIP auswählen.

Desktop vs. Mobile: Skills nutzen geht überall (Desktop & Mobil). Anthropic-Skills einschalten, ZIPs hochladen und Skills verwalten geht nur über Desktop/Web. Einmal eingerichtet, funktionieren sie danach auch am Handy.

03

Wo findest du Skills?

  • Anthropic (offiziell): github.com/anthropics/skills – qualitätsgeprüft und sicher. Empfohlener Startpunkt.
  • Composio – Awesome Claude Skills: github.com/ComposioHQ/awesome-claude-skills – große Community-Sammlung, 50+ Skills. Hier kommen 8 der 10 Skills dieses Guides her.
  • obra Superpowers: github.com/obra/superpowers – Framework für Entwickler, 20+ Skills speziell für professionelles Coding mit Claude Code.
04

Die 10 Skills – Produktivität & Automation

#01 Rube MCP Connector (Community/Composio): ein MCP-Gateway-Server, der Claude mit über 500 Apps verbindet (Gmail, Slack, GitHub, Notion, Linear, Airtable …). Einmal bei Rube authentifizieren, alle Verbindungen laufen darüber – keine separaten API-Keys. Installation: npx @composio/rube-mcp bzw. in Claude Code /plugin install rube.

#02 Superpowers (Community/obra): obras Developer-Toolkit für Claude Code. Fügt drei Befehle hinzu: /brainstorm (durchdenkt Alternativen vor dem ersten Code), /write-plan (Implementierungsplan nach TDD), /execute-plan (Schritt für Schritt mit Validierung). Über 20 vorgefertigte Skills. Installation: /plugin marketplace add obra/superpowers-marketplace → /plugin install superpowers.

#03 Document Suite (offiziell/Anthropic): bereits in Claude integriert. Macht Claude wirklich kompetent in Word, Excel, PowerPoint und PDF – mit echter Formatierung, echten Formeln und professionellen Layouts. Claude wendet die Skills automatisch an, wenn du ein Dokument anforderst. Installation: Customize → Skills → Document-Suite-Toggles einschalten.

05

Die 10 Skills – Design & Kreativität

#04 Theme Factory (Community): gibt Claude 10 vorgefertigte Designthemes mit abgestimmten Farben und Fonts. Du aktivierst ein Theme mit einem Satz, und alle HTML-Artifacts, Präsentationen und visuellen Outputs der Unterhaltung folgen diesem Stil. Eigene Themes aus deinen Lieblingsfarben sind möglich.

#05 Algorithmic Art (Community): generiert p5.js-Generative-Art aus Text-Beschreibungen. Durch Seed-Nummern sind Ergebnisse reproduzierbar („Seed 42" ergibt immer dasselbe Bild). Ausgabe: interaktiver HTML-Viewer, PNG/SVG-Export und bearbeitbarer Code. Unterstützt Flow Fields, Partikel-Systeme, rekursive Muster.

#06 Slack GIF Creator (Community/Composio): erstellt für Slack optimierte animierte GIFs. Kennt Slacks 2-MB-Limit und optimiert automatisch. Du beschreibst in normaler Sprache, was du möchtest.

Installation (04–06): GitHub-Ordner von ComposioHQ/awesome-claude-skills als ZIP komprimieren → Customize → Skills → Upload.

06

Die 10 Skills – Code & Entwicklung

#07 Webapp Testing (Community): schreibt und führt Playwright-Automatisierungstests aus (Chrome, Firefox, Safari). Du beschreibst, was getestet werden soll; Claude schreibt den Test-Code, führt ihn aus und liefert einen Bericht. (Playwright muss installiert sein.)

#08 MCP Builder (Community/Composio): generiert produktionsreifen MCP-Server-Boilerplate in TypeScript oder Python (FastMCP) – mit Error-Handling, Rate-Limiting, Input-Validierung, Logging und Security. Was sonst 2–4 Stunden Setup kostet, dauert unter 15 Minuten.

#09 Brand Guidelines (Community/Composio): speichert vollständige Brand-Identitäten (Hex-Farben, Fonts, Tonalität, Schreibregeln). Anders als Theme Factory lassen sich mehrere komplette Marken verwalten und jederzeit wechseln – ideal für Agenturen.

#10 Systematic Debugging (Community): erzwingt ein striktes 4-Phasen-Framework – 1) Beweise sammeln, 2) Muster analysieren, 3) Hypothesen minimal testen, 4) implementieren und dokumentieren. Eiserne Regel: KEIN Fix ohne Root Cause. Ergebnis laut Guide: ~95 % First-Fix-Rate statt ~40 %.

07

Empfehlungen: so fängst du am besten an

  • Fang mit Document Suite an – er ist bereits eingebaut. Customize → Skills → Toggles bei Word, Excel und PowerPoint einschalten (unter 30 Sekunden), dann Claude um einen Excel-Report oder eine PowerPoint bitten.
  • Rube + Superpowers sind „Daily Drivers" – Skills, die du bei jeder Session nutzt: Rube zum Verbinden deiner Apps, Superpowers für Entwickler mit Claude Code.
  • Maximal 20–50 Skills gleichzeitig aktiv halten. Claude lädt beim Start die Metadaten aller aktiven Skills (je ~30–50 Token). Bei 100 Skills werden tausende Token verschwendet und Claude wird langsamer. Faustregel: nur aktiv halten, was du regelmäßig nutzt.
  • Community-Skills kurz prüfen: Öffne die SKILL.md im ZIP, bevor du hochlädst. Die Repos von anthropics/skills und ComposioHQ/awesome-claude-skills sind community-geprüft; bei unbekannten Quellen kurz reinschauen.
